# Casting integrity audit (0.13.0)

Written 2026-11-10 against the code at `41983b5` (0.12.8). The assignment named a baseline of v0.4.0; the repository was already at 0.12.8, so this audit covers that code. Every cause below has code evidence (a file and what it did) and a test that fails on the old behaviour and passes now. A suspected cause that could not be confirmed is listed separately, with how it was checked.

The path traced: character definition (`script.ts`, `types.ts`) → voice discovery (`castcall.ts`, `Voices.tsx`, `finder.ts`) → matching (`autocast.ts`, `presets/match.ts`, `agent/services.ts`) → approval (`voiceDna.ts`) → persistence (`ctx.tsx`, `cast.ts`) → generation (`generate.ts`, `Perform.tsx`, `agentEnv.ts`) → playback and export (`manifest.ts`, `markers.ts`, `exportScene.ts`).

## Checked and not confirmed

- **Multi-speaker voices use the wrong speaker.** The Rust command splits `file@N` and passes `--speaker N` (`local.rs`, tested); the TypeScript request sends the id unchanged (`clipRequest`, tested); and all 24 L2-ARCTIC speaker numbers in `castcall.ts` were compared with the model's own `speaker_id_map` (`app/src/fixtures/l2arctic.speakers.json`, downloaded 2026-11-10 from `rhasspy/piper-voices`): every name matches its number. No defect.
- **Character ids change during script edits.** Ids are `c-<slug of the name>` and are kept while the name is kept (`parseScript` reuses the existing character). Renaming a speaker in the script creates a new character; two characters with the same name are one character. Both are by design and documented as limits.
- **Stale audio cache.** `media.ts` caches by take id only. Ids are random and takes are never overwritten (`take_write` refuses), so no misattribution was found. A cross-project id collision is theoretical.
- **Inference workers ignoring the selected voice.** Piper, Kokoro, Qwen and Wazobia each take the voice from the request; the Kokoro and Qwen voice names are checked against an allowlist before a process starts.

## What this audit does not show

It shows how the code behaved and that the rules now hold in tests with fixture voices. It does not show how any voice sounds, whether an accent is convincing, or whether a voice's recorded gender or age is right: only listening can.
